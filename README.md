# Blender-Add-on

Blender add-ons for game asset work. Both need Blender 4.2+ (tested up to 5.1). Install each folder as a zip:
*Edit > Preferences > Add-ons > Install from Disk*.

| Add-on | Folder | What it does |
|---|---|---|
| **Nature Forge** | [`nature_forge/`](nature_forge/README.md) | Geometry Nodes generators for **rocks, cliffs, mountains and trees** (plus *Rockify* for your own meshes) with live controls for shape and depth. Texture sets from your library folders are connected automatically, and their height map becomes real 3D detail. Auto-paint layers (moss, snow, dirt, edge wear ...) and vertex painting. |
| **Material Layer Mixer** | `material_layer_mixer/` | Substance-style material layers and painted masks, 3D surface from height, and baking to game LODs / Roblox. Nature Forge objects bake directly with its *Bake LODs*. |
